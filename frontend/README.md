# Sistema de Gestión de Eventos

Proyecto Full Stack desarrollado con:

- React
- Vite
- Node.js
- Express
- MariaDB / MySQL

## Funcionalidades implementadas

### Gestión de eventos

- Crear eventos
- Listar eventos
- Editar eventos
- Eliminar eventos

### Dashboard

- Total de eventos
- Total de cupos disponibles

### Base de datos

Tablas:

- categorias
- eventos
- usuarios
- inscripciones

## Tecnologías

### Frontend

- React
- Vite
- CSS

### Backend

- Node.js
- Express

### Base de datos

- MariaDB
- MySQL

- GitHub
